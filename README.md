# CopyImageURL Chrome Extension

![Extension Demo](demo.gif)

**CopyImageURL** is a simple Chrome extension that allows users to **copy image URLs and concatenate them** into a single string.

## 📌 Features
- Right-click on an image and select **"Copy Text and Image URL"**
  *The menu is written in Japanse. Please change code if you want.
- Collect multiple image URLs in a **concatenated format (separated by `;`)**  
- Easily clear the stored URLs when needed  

## 🛠 Installation
1. **[Download the ZIP from GitHub](https://github.com/islnd86/CopyImageURL_ChromeExtension/archive/refs/heads/main.zip)**
2. Extract the ZIP and open the folder  
3. Open Chrome and go to `chrome://extensions/`  
4. Enable **Developer Mode** (toggle at the top right)  
5. Click **"Load unpacked"** and select the folder  
6. The extension is now installed 🎉  

## 🚀 How to Use
1. **Right-click** on an image  
2. Select **"Copy Text and Image URL"**  
3. Repeat the process for multiple images (URLs will be concatenated)  
4. **Paste the copied URLs** anywhere you need  
5. **To clear the stored URLs**, use the reset option
